## The app

Exile Compass is a free Windows desktop app that shows a Path of Exile leveling build, quests, Labyrinth trials and related notes in windows over the game, checks item prices on the official trade site, and can show your character in your Discord activity. It is free for personal, non-commercial use.

## How it works with the game

The app reads the game's log file (`Client.txt`) and shows its own windows. It sends keys to the game only when you press one of its keys, one command per press, and only when the game window is in front:

- the price check key sends `Ctrl+Alt+C` so the game copies the hovered item;
- the vendor search key pastes your search string into the vendor's search box;
- the exit key types `/exit` in the chat.

It does not read game memory, modify the game client or automate gameplay. You are responsible for following Grinding Gear Games' Terms of Use and the trade site's rules, including its request limits.
